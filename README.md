<h1 align="center">music-server-cloud</h1>

<br/>

## 项目说明

保持理智音乐网站 前端使用**Vue**，后端使用**SpringCloudAlibaba**，基于[music-website](https://github.com/Yin-Hongwei/music-website),主要包含李志、赵雷

## 项目功能

- 音乐播放
- 用户登录注册
- 用户信息编辑、头像修改
- 歌曲、歌单搜索
- 歌单打分
- 歌单、歌曲评论
- 歌单列表、歌手列表分页显示
- 歌词同步显示
- 音乐收藏、下载、拖动控制、音量控制
- 后台对用户、歌曲、歌手、歌单信息的管理

<br/>

## 技术栈

### 后端

**SpringCloudAlibaba + Nacos + Dubbo + SpringSeurity + Sentinel + MyBatis-plus + Redis**

### 前端

**Vue3.0 + TypeScript + Vue-Router + Vuex + Axios + ElementPlus + Echarts**
